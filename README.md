# BOYPROVOD Player

Base unificada para Web/PWA + Android/Android TV, com arquitetura preparada para Samsung Tizen, LG webOS e Roku.

## Objetivo inicial
- Portal web otimizado para TV e controle remoto
- Cliente Android/Android TV com Media3/ExoPlayer
- API compartilhada para autenticação, catálogo, favoritos e dispositivos
- Player com HLS/M3U8 e fallback de fontes
